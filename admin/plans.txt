Sequence of Play:
	The game is played in turns. Each turn, the players will move through the following Phases in order:
		- Projects Phase:
			- Any Projects that have met or exceeded the Time and Budget minimal values printed on 
			their card are now completed and scored. 
			- See below for process. 
			- Remove completed Project cards and dice from their box on the Game Mat; 
			if more Projects remain to be played, the Country player will now replace Project cards 
			in the empty boxes (the player may choose the new project and which box it goes into).
		- Turn End Phase:
			- If all Projects planned to be played in the game have been completed, 
			end the game and determine Victory Level. 
			- If not:
				- Raise the Time value of all Projects in play by 1, unless the Project’s Budget value 
				is currently 0 (zero); then start a new turn with the Draw Cards Phase.

Completing a Project:
	During the Projects Phase, if both dice on a Project card show values 
	that equal or exceed the minimal values printed on the card, the project is completed. 
	Note the die values, calculate the project’s Completion Cost, and award the Jedburgh player any 
	Victory Points they are due. Remove the Project card and dice. 
	Note that when a project is completed, there is an additional effect that is applied immediately 
	(and which may cause further projects to be completed, in the same Phase).
	Projects that are completed may be “recycled” and placed in empty boxes until the total number of 
	completed Projects for the game is reached. 
	In either case the Country player may choose which Project is to be placed; 
	place the two dice showing their initial values of 0 (zero).

Victory Points and Victory Scale:
	Victory Points:
		Only the Jedburgh player gets Victory Points.
		The Victory Point value of a completed project is equal to its Completion Cost 
		(the two die values multiplied together at completion) 
		minus its Planned Cost (the two minimal values printed on the card multiplied together). 
		Record accumulated Victory Points on the track on the Game Mat. 
		Place a marker in the “+ 100” box when passing this total.

Example: 
	A Small Port is completed. The die values are 5 for Time and 4 for Budget, for a Completion Cost of 5 x 4 = 20. 
	The Planned Cost of the project is 4 x 3 = 12. 
	The Jedburgh player adds 8 Victory Points and the Country player adds 1 to either die value of any Project in play. 
	They choose Administrative System; adding 1 to the Budget value completes it on time and on budget, 
	so the Project is immediately scored. 
	Jedburgh does not get any Victory Points and the Country player moves the HN Influence Track marker 2 boxes 
	to the left.

Victory Scale. 
Add the total Planned Costs of all Projects that were completed. 
Compare this total to the number of Victory Points. 
Country wins if Blue’s Victory Points are less than 2.0 times this total. 
Jedburgh wins a Tactical Victory if they have 2.0 to 2.99 times the total, 
and a Strategic Victory if they have 3.0 times the total or more. 
We will likely have to vary these ratios after some playtesting.

However, the assumption in the Turn End Phase is that work on a project proceeds unless its budget is zero 
(indicating it has not really been started yet). 
Meanwhile, project budgets can only ever be increased; any money already spent is a sunk cost 
(so think of the Highway System Project, which actually loses Victory points for the Jedburgh player when completed, 
as a stand-in for any number of make-work projects and initiatives that simply inject money into the 
local economy and would be viewed positively by the locals and their government).
